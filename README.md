# MDV Web Design website

Plain HTML, CSS and JavaScript, hosted on Netlify. Every change pushed to `main` goes live automatically.

## Making changes

The easiest way is to ask Claude in the "Website Creation" project what you want changed. It edits the files here and the site updates on its own.

To edit yourself, open a file on GitHub, click the pencil icon, make the change and click **Commit changes**. Text lives in `index.html` and colors and layout in `styles.css`.

Note: `index.html`, `404.html` and `thanks.html` are generated by `_source/build.py`. Small hand edits are fine, but they get overwritten the next time the generator runs, so tell Claude about any change you make by hand.

## Preview locally

```
node serve.js
```

Then open http://localhost:5173.

## Rebuild the pages

```
python3 _source/build.py .
```

## Case studies

The J. Carrillo and Christina's Salon case studies stay off GitHub and off the live site until those businesses give permission. `_redirects` also blocks `/work/*`, `/_source/*`, `serve.js` and this README from being served.

## Form emails

In Netlify go to **Site configuration → Forms → Form notifications → Add notification → Email notification**. Choose the `quote` form and `markdv.webdesign@gmail.com`.
